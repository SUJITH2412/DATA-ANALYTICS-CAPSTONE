## 🔍 Project Approach
1. **Data Understanding**
   - Analyzed dataset structure and key columns  

2. **Data Cleaning**
   - Removed duplicates  
   - Handled missing values  
   - Standardized formats  

3. **Data Analysis**
   - Used Excel for visualization (charts, pivot tables)  
   - Used SQL for querying and insights  

4. **Insight Generation**
   - Interpreted results and documented findings  

## 📊 Key Insights
- Identified diseases with the highest patient admissions  
- Found conditions with higher treatment costs  
- Observed peak hospital admission periods  
- Analyzed doctor-wise and department-wise workload distribution

- Limited patient history  
- No geographical data  
- No long-term historical trends  
- Lack of detailed clinical information
